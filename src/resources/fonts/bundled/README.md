# Bundled preview font

Unmodified Noto Sans SC Regular 2.004, Copyright © 2014–2021 Adobe.

Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf

License: SIL Open Font License 1.1 (`OFL.txt`), also distributed in
`public/licenses/NotoSansSC-OFL.txt` so production builds retain the notice.
The original copyright and font names remain embedded in the font.

This is a lazy-loaded, same-origin preview recovery resource. It is never
selected automatically for formal exports and never changes saved font choices.
It covers common Chinese/Japanese calendar text and ASCII; unsupported characters
are reported explicitly rather than rendered as missing-glyph squares.
